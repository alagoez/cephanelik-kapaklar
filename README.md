# Cephanelik — Kapak Görselleri

Bu depo, Notion'daki **Cephanelik** sayfalarının kapak görsellerini barındırır.
Her dosya bir Notion sayfasına ait; dosya adı o sayfanın kimliğidir.

- 134 poster, 1500×600 PNG
- Fight Club görsel dili: siyah zemin `#080808`, kırmızı `#dc2626`,
  Anton büyük harf başlık, Special Elite kicker ve kural damgası
- Altı farklı kompozisyon varyantı, sayfa kimliğinden kararlı olarak türetilir

Üreten script projede: `_uretim/poster.py` (+ `sayfalar.py`, `fontlar/`).
Görseller yeniden üretilirse dosya adları değişmez, Notion cover'ları kırılmaz.

Fontlar Google Fonts'tan: Anton (OFL), Special Elite (Apache 2.0), Space Grotesk (OFL).
